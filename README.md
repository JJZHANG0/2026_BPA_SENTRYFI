What does a fall look like to a radio? SENTRYFI lets you pause a simulated fall at the moment of imbalance and inspect the same instant from three perspectives: the person's posture, the signals at three receivers, and the activity templates that best match those signals. A companion exploded view shows how a sensing node fits inside its enclosure.

### A first experiment: bending down versus falling

1. Open the sensing view and select **Care room**. The keyframe preview shows the resting pose after a fall.
2. Select **Fall and remain still** to replay the full sequence. Watch the three link traces as the person enters, loses balance, and comes to rest.
3. Switch to **CSI details**. Select a receiver and compare amplitude with relative phase across the 56 active subcarriers.
4. Play **Pick up an object** in the same room. Compare the return to standing with the fall sequence, then use **Activity matching** to inspect how the candidate rankings evolve.

## Reading the simulation

**Channel state information (CSI)** describes how a wireless channel changes the amplitude and phase of individual subcarriers. In this model, each receiver sees a direct path plus reflected paths. Moving the simulated body changes path lengths and attenuation, so the same motion produces different traces at different receivers.

| Signal view | How to read it |
| --- | --- |
| Link trends | Each trace shows change relative to that receiver's empty-room baseline. The time cursor links the plot to the 3D pose. |
| Single-packet CSI | Inspect the frequency profile of one receiver at one instant. The HT20 example uses 56 active subcarriers, with phase referenced to subcarrier −1. |
| Template heatmap | The matcher combines amplitude and relative-phase features from all three links over a one-second window. A smaller root-mean-square distance to a template produces a higher similarity score. |

The motion sequences, CSI frames, and reference templates are generated by the simulation. Scores express similarity within this model. Real-world fall-detection accuracy would require independent evaluation on measured CSI.

## Hardware and data flow

The design uses four ESP32-S3 SuperMini boards. Firmware assigns one transmitter and three receiver roles. The sensing view illustrates the following packet path:

```text
TX1  ── numbered ESP-NOW probe ──►  RX1 / RX2 / RX3
                                        │
                                  CSI records over UDP
                                        │
                                        ▼
                                   Wi-Fi router ──► Computer
                                                    Group by probe number
                                                    Compare activity features
```

The hardware viewer places the board, lithium-polymer pouch cell, and slide switch between the two 3D-printed shell halves. The shells use CAD coordinates, and the electronics follow approximate placements from reference photographs.

## Run locally

The repository contains static HTML, CSS, and JavaScript. With Python 3 installed, serve it from the repository root:

```sh
python3 -m http.server 8000
```

Open [localhost:8000](http://localhost:8000/) in a WebGL-capable browser. The public demo is served by GitHub Pages from the root of the `main` branch.
